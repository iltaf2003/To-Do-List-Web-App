# To-Do List Web App

A modern, fully responsive To-Do List application built with HTML, CSS, and JavaScript.

## Features

- ✅ Add, edit, and delete tasks
- ✅ Mark tasks as completed
- ✅ Progress tracking with visual progress bar
- ✅ Filter tasks (All, Active, Completed)
- ✅ Local Storage persistence
- ✅ Dark/Light theme toggle
- ✅ Fully responsive design
- ✅ Smooth animations and transitions

## How to Use

1. Open `index.html` in any modern web browser
2. Add tasks using the input field
3. Click checkboxes to mark tasks complete
4. Use Edit/Delete buttons to modify tasks
5. Filter using All/Active/Completed buttons
6. Toggle theme with the moon/sun icon
7. Clear completed tasks when needed

## Files

- `index.html` - Main HTML structure
- `style.css` - Modern responsive styling with themes
- `script.js` - Application logic and functionality
